## tasty-desserts-store

This is an e-commerce store that features a bakery store with
delicious desserts to enjoy.

## Description

The website features the shopping experience of the store.
Users can add their favorite desserts to a cart modal that
will calculate their total as they shop. You can
add and remove your treats and watch how the product
cards change color to indicate whether it is in your shopping
cart already. When you're ready to checkout, you can proceed to
pay, and you will instantly be received with a order confirmation
that displays your desserts and the total price in USD.

## Tech Stack

- REACT JS
- TailwindcCSS
- HTML

### Dependencies

- React-Scroll (gives a new scrolling effect when confirming order.)
